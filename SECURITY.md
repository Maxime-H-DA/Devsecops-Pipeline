# Security Policy

## Supported versions

Only the `main` branch is maintained. It is the version deployed in production.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Maxime-H-DA/Devsecops-Pipeline/security/advisories/new).

I will acknowledge your report within 7 days, keep you informed until it is resolved, and coordinate the public disclosure with you once a fix is available.
